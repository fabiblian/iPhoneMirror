# Hinweise für Agenten in diesem Fork

Wenn eine Aufgabe Fabians lokalen Test von USB-Mirroring, Wireless Control oder AirPlay betrifft, lies zuerst [die persönliche Übergabe](LOKAL_NICHT_OFFIZIELL/AGENTS.md). Die Übergabe ist eine datierte, nicht offizielle Testnotiz; prüfe den aktuellen Zustand erneut. Für andere Aufgaben gelten weiterhin die normalen Projektdateien und Anweisungen.

Wenn eine Aufgabe die Texte der Oberfläche, die ⓘ-Hinweise (`InfoTip`/`InfoRow`) oder den Branch `ui/less-text` betrifft, lies zuerst [die Übergabe „Weniger Text“](LOKAL_NICHT_OFFIZIELL/ui-weniger-text/UEBERGABE.md).
